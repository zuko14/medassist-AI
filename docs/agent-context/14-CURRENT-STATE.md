## 2. SUMMARY OF TECHNICAL REALITIES FOR FUTURE AGENTS

1. **Never Assume RLS Protects Data**: Every query on a tenant table must explicitly include `.eq("clinic_id", clinic_id)` or use `scoped_query()`.
2. **Never Execute PostgREST Queries Synchronously on the Async Loop**: Always wrap Supabase client calls with `await sb(...)`.
3. **Never Make WhatsApp Webhook Synchronous**: Keep `POST /webhook` under 15ms.
4. **Never Modify `admin/admin.js`**: Edit [`admin/index.html`](file:///c:/Users/chait/OneDrive/Desktop/SYSTEMS_ALL/KriyaAI/admin/index.html) directly.
5. **Never Allow AI to Prescribe or Diagnose**: All clinical safety rules in `ClinicalFirewall` must remain deterministic and zero-LLM.
