Bulk Import Diagnostic Catalog

Upload a CSV file to create or update diagnostic tests and pricing.

Specifications & Policy:
• Required Columns: name, price_rupees
• Optional Columns: category, sample_type, turnaround_hours, fasting_required, prep_instructions
• Service type: set it below to file the whole file at once, or add a category column to set it per row. A file with neither leaves existing service types untouched.
• Limits: Max 5 MB file size & 25,000 data rows.
• Atomic Guarantee: If any row fails validation, zero changes are saved to the database.

This is how a centre actually holds its catalogue: one export per section. Upload pathology, then health packages, then radiology — each under its own service type. Patients then choose the service type first instead of scrolling one endless list.

Import Diagnostic Price List

Supported Formats & Safety Limits:
• Formats: Excel (.xlsx), CSV, PDF (up to 30 pages), Images (PNG, JPG)
• Upload Limits: Max 10 MB upload size; OCR limited to 10 pages; legacy .xls must be saved as .xlsx or CSV
• Staging Guarantee: Zero unapproved writes to your live catalogue. You review every row before applying.
